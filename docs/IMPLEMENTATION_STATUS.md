## 主要クラス
| クラス | 責務 |
|---|---|
| `Game`（オートロード） | データ・セッション・設定・シーン遷移・自動セーブ |
| `GameSession` | 1プレイの全状態と、回収・使用などの操作 |
| `ActionSystem` | 全行動の必要条件検証・素材の預かり・完了時再検証・成功/失敗/中断の処理 |
| `Inventory` | 所持品（スタック／耐久度付き個体）、重量制限 |
| `SurvivalState` | 生存パラメータ、効率、気絶 |
| `Raft` | 床タイルと建築物 |
| `GameClock` | ゲーム内時間 |
| `Crew` | 仲間の状態・作業・人間関係・離脱・再加入 |
| `DialogueRunner` | 会話の進行・選択肢の条件・効果 |
| `CombatSystem` | 戦力計算・戦闘解決・結果の適用 |
| `FactionSim` | 勢力の状態と自律シミュレーション・プレイヤーへの襲撃判定 |
| `Fleet` | 船舶・乗組員・艦隊任務の解決 |
| `Trade` / `Piracy` | 交易・外交／海賊行為・捕虜 |
| `Conditions` | データ駆動の条件式（加入・会話・今後のイベント/クエストで共用） |
| `SaveManager` | 保存・読込・検証・バックアップ復旧 |
| `GameData` / `DataValidator` | データ読込・検証 |
