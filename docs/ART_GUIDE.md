# アートガイド (ART_GUIDE)

## 基本方針
- 世界は**ローポリ3D**。ただし「安っぽい単純ポリゴン」にしない。面の向きが分かるフラットシェーディング、海域ごとの色彩、時間帯の照明、遠景の霧で奥行きを出す。
- キャラクターは**イラスト調**。会話は2D立ち絵、探索は対応する3Dモデル（外見を一致させる）。

## 形状ルール
| 対象 | ルール |
|---|---|
| 海面 | 約3〜4mのポリゴン面。6成分の正弦波で変位させ面法線で陰影（`scripts/world/ocean.gdshader`）。CPU側も同じ式（`ocean_waves.gd`）で筏を揺らす |
| 木材 | 板は幅をそろえず色を4段階でばらつかせる。角は丸めない |
| 金属 | 錆色・灰色。エッジを少し欠けさせる |
| キャラクター | 円柱（6〜8分割）と球（8分割）を基本単位。頭身は約5.5 |
| 漂流物 | 遠くから判別できるシルエット（板＝細長、樽＝円柱、木箱＝立方体）と小さな光点 |

## 色彩基準（仕様10）
| 用途 | 色 | 例 |
|---|---|---|
| 通常の海 | 青緑・ターコイズ | 浅 `#1b9a98` / 深 `#0a3f66` |
| 深海 | 濃紺・青黒 | `#06203a` / `#020a14` |
| 廃墟 | 灰・錆 | `#6e6a66` / `#8a4b2a` |
| 木材 | 自然な茶 | `#8a5a33` `#9b6a3d` `#7c4f2c` `#a4743f` |
| 危険海域 | 暗赤・紫・濁った緑 | `#5a1e24` / `#3e2a55` / `#4a5a2e` |
| 安全な拠点 | 暖色の光 | ランタン `#ffb35c` |
| 重要な遺物 | 淡い青白・落ち着いた金 | `#cfe8ff` / `#c9a45a` |

海域ごとの色は `data/world/world_zones.json` の `ocean_shallow_color` / `ocean_deep_color` / `fog_color` で定義する。

## 照明
- 6時日の出・18時日没。夕方は太陽光を `#f0a060` 寄りに。
- 夜は月光（`#9db8e8`, 弱）＋筏のランタン（暖色）。完全な暗闇にしない。
- Compatibility レンダラー前提。トーンマップは線形、空の映り込みは無効（DECISIONS D-008）。

## UI
- 背景パネル: 深い青緑 `#0d2130` 不透明度0.88、角丸14px、細い水色の縁。
- アクセント: 金 `#f2cc73`（見出し）、警告 `#ff8c6b`、充足 `#8eeba5`。
- フォント: Noto Sans JP。最小文字サイズ15px（説明文）、ボタン22px以上、タッチ部品は最小 56px 角。
- 重要ボタンは画面端から36px以上離す（誤操作防止、仕様37）。

## 撮影による確認
`xvfb-run ... --script res://tools/smoke_test.gd` で `build/screenshots/` に昼・建築・夜の画面を出力し、色調の確認に使う。
