# 既知の問題 (KNOWN_ISSUES)

| ID | 重大度 | 内容 | 状況・回避策 |
|---|---|---|---|
| KI-001 | 高 | Android 実機・エミュレーターでの動作が未検証 | 開発コンテナに KVM がなくエミュレーター不可。ユーザーの実機での確認が必要（README のインストール手順） |
| KI-002 | 中 | 3Dモデル・2Dイラストがすべて仮素材（プリミティブ） | Blender・画像生成ツールが環境にない。ASSET_STATUS で管理 |
| KI-003 | 低 | ヘッドレス実行時に `Parameter "m" is null (mesh_storage.h)` エラーが出る | ダミーレンダラー固有のメッセージ。描画ありの実行では発生しない。テストには影響なし |
| KI-004 | 低 | 終了時に `ObjectDB instances leaked` 警告 | 静的キャッシュ（UiTheme/LowPoly のマテリアル）由来。動作に影響なし |
| KI-005 | 低 | 効果音・BGM は数式合成の簡素なもの | 正式な楽曲・効果音は今後差し替え可能（assets/audio/ に同名WAVを置く） |
| KI-006 | 中 | リリース署名の鍵が未作成 | ストア公開時に作成。鍵はリポジトリに含めない |
| KI-007 | 低 | 筏の上を歩けない（キャラクターは中央に立つのみ） | フェーズ5で筏上の歩行・泳ぎを追加予定（DECISIONS D-010） |
| KI-008 | 低 | 勢力の船は3D世界に表示されない（自分の船は筏の横に停泊表示） | 描画負荷を抑えるため（D-031） |
| KI-009 | 低 | 潜水は時間行動として処理され、水中の3Dシーンはない | D-023 |
| KI-010 | 解決 | 仲間の作業中アニメーション | 作業中は腕を振り、夜は座って休む（仮の手続きアニメーション） |
